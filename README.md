# 御膳房餐饮管理系统 V2.0

> 纯前端实现的餐饮管理系统，无需后端服务器和数据库，打开即用。

## 项目简介

御膳房餐饮管理系统是一个基于 HTML/CSS/JavaScript 的纯前端 Web 应用，模拟餐厅从点餐到管理的完整业务流程。数据使用浏览器 localStorage 持久化存储，无需任何后端环境配置。

## 功能模块

### 登录页

- 三种角色：顾客 / 商家 / 管理者
- 用户注册与登录（邮箱 + 密码）
- 游客模式（免登录直接点餐）
- 表单实时验证

### 售卖页（顾客端）

- 三种点餐方式：堂食（选桌台）/ 外卖（填地址电话）/ 自提
- 菜品浏览：搜索、分类筛选
- 购物车：增减数量、实时计算总价
- 三种支付方式：支付宝 / 微信 / 银行卡
- 订单生成与历史记录

### 管理员页（后台）

- **数据看板**：用户数、菜品数、订单数、营收统计
- **用户管理**：增删改查用户信息
- **菜品管理**：增删改查菜品（名称、价格、库存、分类、图片）
- **订单管理**：查看订单详情、标记完成、删除订单
- **权限控制**：仅商家/管理者可访问，顾客与游客被拦截

### UML 设计图

- 用例图
- 类图
- 活动图（2张）

## 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 | 页面结构 |
| CSS3 | 样式与响应式布局 |
| JavaScript (ES6+) | 交互逻辑 |
| Font Awesome | 图标库 |
| localStorage / sessionStorage | 数据持久化 |

## 快速开始

1. 克隆仓库

```bash
git clone https://github.com/Magic-xq/Restaurant-management-system.git
```

2. 用浏览器打开 `登录页.html` 即可运行

> 无需安装任何依赖，无需配置服务器。
